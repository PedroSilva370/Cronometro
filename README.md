# Cronômetro de Tarefas

Um projeto pessoal desenvolvido em Python para gerenciar tarefas e utilizar um cronômetro diretamente pelo terminal.

> **Aviso:** O código foi desenvolvido em português.

---

## Funcionalidades

- Iniciar cronômetro
- Adicionar tarefas
- Visualizar tarefas cadastradas
- Iniciar uma tarefa específica
- Sistema simples e interativo no terminal

---

## Tecnologias

- Python 3
- Biblioteca padrão (`time`)

---

## Como Executar

```bash
python sistema.py
```

---

## Menu do Sistema

```text
[1] Iniciar cronometro
[2] Adicionar tarefa
[3] Ver Tarefas
[4] Iniciar Tarefa
[5] Sair do Sistema
```
